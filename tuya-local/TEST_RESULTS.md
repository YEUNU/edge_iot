## 추가 검사에서 수정한 문제

- 연결 실패 시 온라인 상태가 남던 문제: 실패 시 오프라인, 이후 정상 조회 시 복구.
- HTTP 200 응답의 JSON이 객체가 아닐 때 처리 누락: 비정상 응답으로 거부.
- 비동기 프로필 변경 중 설정 값이 유실되던 문제: 프로필 적용 후 조회에서 다시 발행.
- 재시작 후 이전 온도·풍량·모드 소실: 기종별로 원자적 저장·복원. 실제 전원 상태는 추정하지 않음.
- 유휴 Tuya 소켓의 일시적 실패: IR을 보내지 않는 상태 조회만 연결을 열어 한 번 재시도. 응답이 불확실한 IR 명령은 재전송하지 않음.
