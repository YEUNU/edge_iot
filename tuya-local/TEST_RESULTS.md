  마지막 IR 명령 기록, 선택한 코드셋, 저장 설정은 그대로 유지한다.
- 재시도는 IR을 송신하지 않는 상태 확인에만 적용한다. 실제 제어 명령은
  응답을 잃어도 중복 전송하지 않는다. 새 객체도 실패하면 오류를 반환한다.
- `python3 -m unittest discover -s tests -p 'test_tuya*.py'`: 52개 통과.
  소켓을 닫아도 남는 오류의 복구, 상태 보존, 명령 중복 방지, 재시도 상한을 검증했다.
- 브리지 이미지를 재빌드하고 운영 컨테이너에 배포했다.
- 배포 컨테이너와 소스의 SHA-256 일치를 확인했다. 실제 브리지 조회가
  20초 간격으로 3회 성공했고, 주기적 갱신 이후 SmartThings ONLINE을 확인했다.
  에어컨 전원·온도 명령은 보내지 않았다. 장시간 장애 재발 방지는 모의 회귀
  테스트로 검증했으며, 동일한 내부 장애를 실기기에 재현한 것은 아니다.
