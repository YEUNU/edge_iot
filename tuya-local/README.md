# Tuya 에어컨 로컬 제어

SmartThings Edge → LAN HTTP 브리지(Docker) → Tuya IR 허브 → 적외선 에어컨.
브리지는 Docker 컨테이너로만 운영하며 실행 중 Tuya 클라우드 API를 호출하지 않습니다.

## 제조사별 기종 분류 (72개 코드셋)

에어컨 리모컨의 **최저 설정 온도(16°C / 17°C / 18°C)**, **난방 지원 여부**, **리모컨 형태(온도 표시형 vs 버튼형)**에 맞는 항목을 선택해 시험합니다.

## 브리지 설치 및 실행 (Docker)

```sh
cd tuya-local/bridge
mkdir -p data state
chmod 700 data state
cp config.example.json data/config.json
chmod 600 data/config.json
# data/config.json에 IR 허브의 device_id, local_key, ip, api_token(32자 이상 영문/숫자) 입력
TUYA_BIND_IP=192.168.1.100 TUYA_UID=$(id -u) TUYA_GID=$(id -g) docker compose up -d --build
```

- 컨테이너에는 `data/config.json`(읽기 전용)과 `state/`만 마운트됩니다.
- 컨테이너 실행 중 상태 확인은 HTTP API(`/v1/state`)로 수행합니다. `service.py check`·`inspect`는 브리지 중지 후 단독 점검 시 사용합니다.

## SmartThings 연결 및 사용

1. 허브에 드라이버를 설치하고 **기기 추가 → 주변 검색**으로 `Tuya 에어컨 로컬`을 추가합니다.
2. 저장소 루트에서 자동 연결 도우미를 실행합니다.

   ```sh
   python3 tuya-local/bridge/connect_smartthings.py
   ```

   120초 유효한 일회용 티켓을 허브에 전달해 LAN에서 브리지 토큰을 자동 교환·저장합니다.
3. 앱의 `기종 설정`에서 제조사·기종을 고른 뒤 전원·온도·모드·풍량을 시험하고 `반응 확인 · 기종 저장`을 누릅니다.
4. IR은 단방향이므로 기기 상태에 선택된 기종과 함께 마지막 전송 기준(`캐리어 18~30°C 냉난방 · 정상 연결 (마지막 전송)`)이 표시되며, 재시작·기종 변경 직후에는 `전원 미확인 (마지막 설정)`으로 나타납니다. 버튼 전용 기종은 `선택한 버튼 보내기`로 송신합니다.
