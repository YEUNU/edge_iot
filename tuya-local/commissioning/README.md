# 최초 데이터 확보 도구

이 폴더는 실행 서비스가 아닙니다. Docker 이미지에 포함하지 않으며 브리지나 SmartThings 드라이버에서 호출하지 않습니다. 여기의 Tuya API 도구만 최초 수집 시 인터넷을 사용합니다.

```sh
python3 tuya-local/commissioning/inventory_cloud.py --data tuya-local/bridge/data --rules
```

해당 허브와 에어컨 카테고리(5)를 기준으로 제조사, 리모컨 인덱스, 인덱스별 API 코드 레코드를 수집합니다. 성공한 파일은 재사용하며 중단 뒤 재실행할 수 있습니다. IR 전송, 가상 리모컨 추가·삭제, 현재 에어컨 변경은 수행하지 않습니다. 인증값과 수집 원문은 Git에서 제외한 `bridge/data/`에만 저장합니다.

2026-09-16 수집 결과:

- 제조사 729개, 중복 제외 리모컨 인덱스 1,325개.
- 모든 인덱스의 rules 조회 완료. 비어 있지 않은 API 코드 레코드 163,693개.
- 37개 인덱스는 비어 있지 않은 코드를 반환하지 않음.
- 이 결과는 이 허브에 제공되는 API 목록이며 실제 에어컨 호환성 검증 결과가 아님.

현재 API의 `code` 문자열은 실행 서비스가 사용하는 검증된 `head`/`key1` 신호와 다릅니다. 이 수집기는 이를 추측해서 변환하거나 로컬 제어 UI에 등록하지 않습니다. 전체 로컬 지원에는 이 레코드에서 실제 신호를 확보·검증하는 작업이 추가로 필요합니다. 현재 설치된 로컬 코드북은 기존 313개입니다. 공개 가능한 수집 범위는 `COVERAGE.json`에 기록합니다.

`export_cloud.py`는 이전 Carrier 설정의 신호 확보에 사용한 별도 도구입니다. 실제 IR 명령이 나가므로 허브를 가린 상태에서만 사용하며 `--hub-covered`가 필요합니다. 전체 1,325개 인덱스의 자동 변환기로 사용할 수는 없습니다.
