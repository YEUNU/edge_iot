# 4개 브랜드 로컬 지원 완료 조건

기존의 전 브랜드 지원 계획을 삼성·LG·캐리어·위니아 전체로 변경했다. 완료 기준은 Tuya 목록의 71개 고유 코드셋과 7,723개 키, 그리고 기존 작동 확인 Carrier 코드셋의 보존이다. 일부 기종만 확보한 상태를 완료로 취급하지 않는다.

- [x] 주 수집 완료. 요청 저널의 모든 항목에 확정된 결과가 있어야 한다.
- [x] 콘솔 원문 저장과 대조 완료. 누락·모호한 로그·오프라인 실패를 재수집하고 충돌이 없어야 한다.
- [x] 최종 카탈로그에 요청한 71개와 기존 Carrier만 포함. 키·브랜드 별칭·파일·인덱스 일치 검사 통과.
- [x] 모든 원문 버튼과 상태 조합을 브리지 경로로 재생해 원문 전체와 일치하는지 검증. 실제 IR을 반복 방사하지 않는 모의 전송 검사다.
- [x] 삼성·LG·캐리어·위니아만 선택 UI에 표시. 공통 코드셋은 해당 브랜드 모두에서 선택 가능.
- [x] 상태 조합형 및 버튼형 화면 검증. 후보 시험·저장·취소, 온도 슬라이더·모드 및 풍량 드롭다운, 추가 버튼 접근, 없는 기능 처리 확인.
- [x] Docker와 Edge 드라이버 배포. 실행 서비스의 Tuya 클라우드 호출 부재와 지정 허브 외 발신 차단 재확인.
- [x] 인증된 자동 연결과 재시작 후 연결 유지 확인. 기존 Carrier를 선택해 최종 상태 확인.
- [x] 실제 SmartThings 화면 검증. 실제 에어컨의 동작 확인은 사용자 확인과 구분하여 기록.
- [x] 대체된 코드·데이터·생성물 제거와 문서 갱신. 다른 작업의 변경은 보존.
- [x] 공개 대상과 압축 데이터·패키지의 개인정보/비밀값 점검. 개인 수집 원문과 설정은 Git에서 제외.
- [x] 새 커밋에 noreply 이메일 사용, 기존 이력 유지, 일반 푸시 후 원격 커밋 확인.

상세 수집 절차는 [commissioning/README.md](commissioning/README.md), 검증 결과는 [TEST_RESULTS.md](TEST_RESULTS.md)에 기록한다. 자동 검사는 IR 원문의 처리 정확성을 확인하며, 보유하지 않은 모든 에어컨의 물리 호환성을 증명하지 않는다.
