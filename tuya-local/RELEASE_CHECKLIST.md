# Tuya 배포 조건

현재 배포 대상은 삼성·LG·캐리어·위니아 71개 코드셋·7,723개 원문 키와
기존 Carrier `104800501`입니다. 새 카탈로그나 UI를 배포할 때 아래 조건을 확인합니다.

1. 원문 키·브랜드 별칭·파일·인덱스와 실행 가능한 상태표가
   `commissioning/verify_korean_release.py --require-existing` 검사를 통과해야 합니다.
2. 원문 버튼·상태 조합 전체의 모의 재생과 Python·Lua 회귀 검사를 실행합니다.
   실제 기기 호환성과 구분합니다. [검증 범위](TEST_RESULTS.md)를 참고하세요.
3. 화면 변경은 생성기 → capability·presentation·번역 등록 → Edge 패키지 순서로 적용합니다.
   후보 시험·저장·취소와 버튼형 기종, 기종별 온도 범위가 유지되어야 합니다.
4. Docker 이미지에는 실행 코드·카탈로그만 포함합니다. 설정은 읽기 전용 파일,
   상태는 별도 디렉터리로 유지하고 지정 허브 외 발신 제한을 확인합니다.
5. 설치 버전과 컨테이너 소스를 대조하고 주기적 LAN 조회·SmartThings ONLINE을 확인합니다.
   변경한 화면은 실제 모바일 앱에서 별도로 확인합니다.
6. [공개 데이터 검사](../PRIVACY.md)를 실행합니다. 인증값·개인 식별자·원본 수집 로그·
   상태·화면 캡처는 Git에서 제외합니다. 푸시 후 원격 커밋이 로컬과 일치하는지 확인합니다.

수집을 다시 수행할 때의 절차는 [commissioning 안내](commissioning/README.md)에 있습니다.
