지역별 매뉴얼과 펌웨어의 원시 데이터 범위가 다르다. 사용자 조절 범위에는
매뉴얼을 적용하고, 기본값·모드 전환·타이머·건조 진행 상태는 기기가 반환한 값을
사용한다. 공장 초기화·네트워크 초기화·물리적 청소/설치 절차는 원격 명령으로
추가하지 않았다. 제상, 압축기 보호, 장시간 운전 보호는 기기 펌웨어가 담당한다.

MiOT 모델 정의로 속성 주소, 단위, 열거형, 읽기/쓰기 권한을 별도 대조했다:

## 실측과 해석의 한계

이번 기기에서는 스마트로 전환하면 55%, 수면은 50%, 옷 건조는 50%가 조회됐다.
사용자가 본 샤오미 앱의 40%와 현재 MiOT 값이 다르다는 사실까지 확인했다.
매뉴얼에는 옷 건조를 8시간 지속하면 목표를 50%로 바꾸는 동작이 있지만,
이번 50%의 원인이 그것인지, 앱 표시 방식인지까지 입증한 것은 아니다.
샤오미 앱의 표시를 복제하려고 기기 상태를 40%로 덮어쓰지 않는다.

새 예약 코드를 실제 기기로 시험했을 때, 시간을 먼저 쓰고 예약을 켜면 두 쓰기가
성공해도 60분으로 바뀌었다. 활성화 후 시간 설정으로 수정한 다음 720분/남은
720분, 취소, 내부 건조 설정 변경을 확인하고 기존 설정을 복원했다.

8시간 연속 운전, 40분 건조 종료, 물통 채움, 센서·모터 고장은 실제로 유발하지
않았다. 이러한 장시간/고장 상태는 매뉴얼·MiOT 정의와 모의 입력으로 구분 검증한다.
물리적 풍량, 소음, 제습 성능이나 휴대폰 푸시 수신 자체를 API 성공으로 대신하지 않는다.
