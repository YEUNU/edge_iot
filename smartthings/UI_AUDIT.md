# SmartThings 화면 확인 항목

화면 생성물 검사와 실제 앱 렌더링을 구분합니다. 자동 검사만으로 모바일 시각 검증을
완료했다고 표시하지 않습니다. 화면 정의·배포 방법은 [UI 구성](UI.md)에 있습니다.

| 화면 | 확인할 내용 |
|---|---|
| Xiaomi 대시보드 | 실제 전원에 맞는 켜짐·꺼짐 문구와 카드 활성 상태 |
| 선풍기 | 바람 세기·모드·회전·예약 순서, 고정/좌우 회전 선택, 0분 예약 해제 |
| 공기청정기 | PM2.5·필터 잔량, 수동 모드에서 풍량 0–14, 고급 화면의 필터 초기화 |
| 제습기 | 기본 화면의 읽기 전용 현재 습도, 목표 40–70%, 옷 건조에서 조절 불가 |
| Xiaomi 설정·알림 | 미설정 항목 온라인 유지, 한국어 연결 결과·최근 경고·테스트 버튼 |
| Tuya 일상 | 기종별 온도·모드·풍량, 연결 실패·전원 미확인·설정 저장 대기 안내 |
| Tuya 기종 설정 | 4개 제조사, 후보 시험·저장·취소, 버튼형 화면, 선택과 송신의 분리 |

기본·고급 전환 뒤 IP·토큰과 기기 ID가 유지되는지 확인합니다. 한국어 제목뿐 아니라
표시 값·명령 범위·자동화 capability도 대조합니다. 실제 제어 시험은 원래 설정을
복원하며, 필터 초기화처럼 되돌릴 수 없는 작업은 화면 검사만으로 실행하지 않습니다.

## 플랫폼 표현

Android 앱은 일부 표준 capability의 표시 형식을 무시하고 자체 그래프·버튼을 씁니다.
현재 습도·회전은 화면용 custom capability와 표준 상태를 함께 발행합니다.
`pushButton` 상태의 `-`, 카드 간격·색상·아이콘은 앱이 결정합니다.
프로필 변경 안내가 나오면 수락 후 기기 상세 화면을 다시 엽니다.
SmartThings 웹은 모바일 presentation과 시험 버튼을 모두 구현하지 않으므로 모바일
확인을 대신하지 않습니다. 앱 버전별 차이는 실제 화면에서 다시 확인해야 합니다.
