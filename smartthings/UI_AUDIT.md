# 모바일 UI 검증 — 2026-09-16

ADB로 연결한 Galaxy SM-S938N(1080×2340)의 SmartThings 한국어 앱에서 선풍기,
공기청정기, 제습기, 에어컨, Xiaomi 알림, Xiaomi 기기 설정 화면을 확인했다.

## 반영한 변경

- 선풍기: 바람 세기를 첫 조작으로 이동. 회전 선택을 두 개의 세로 버튼에서
  고정/좌우 회전 드롭다운으로 변경. 꺼짐 예약 조작 위치가 약 143px 위로 이동.
  0분이 예약 해제임을 한국어 제목에 표시.
- 제습기: 기본 화면의 큰 습도 그래프를 현재 습도 숫자로 대체. 목표 습도 조작은
  약 y=2222에서 y=1268로 이동해 현재 습도·상태·목표·모드가 첫 화면에 들어옴.
  고급 화면 그래프와 표준 습도 기록·자동화 capability는 유지.
- 공기청정기: 영문 제목을 즐겨찾기 풍량으로 표시하는 것을 실제 화면에서 확인.
- Xiaomi 설정: 미설정 보조 기기에 나타나던 오프라인 경고를 제거.
  연결 확인 3건이라는 정상 검색 결과와 온라인 상태를 API와 화면에서 확인.
- 누락된 기존 사용자 정의 기능 7개의 한국어 번역과 새 화면 기능 2개의 번역을 저장·적용.
  알림·설정 카드가 기본 언어 제목을 사용하는 경우도 한국어가 나오도록 기본 번역 보완.
- 에어컨: 온도 → 모드 → 풍량 → 기종 설정이 첫 화면에 들어와 기존 배치를 유지.

## 1차 검증 당시의 플랫폼 제약과 남은 확인

- Android는 일부 표준 capability의 displayType을 무시한다. 표준 회전은 목록으로
  정의해도 버튼으로, 표준 습도는 state로 정의해도 큰 그래프로 그렸다. 화면용
  capability는 이 동작을 피하면서 기존 표준 자동화 계약을 보존하기 위한 것이다.
- 상태/조작 카드의 그룹 구분, 앱 공통 타이머와 관련 서비스는 SmartThings가 결정한다.
- 알림/설정 상단 제목에 기본 언어 번역을 사용하는 동작을 확인했다. 한국어 번역만
  적용했을 때 남았던 영문 제목은 기본 언어 파일도 보완하여 해결했다.
  앱 데이터 초기화나 기기 재등록은 수행하지 않았다.
- 고급 화면의 모든 항목, 다른 화면 크기·글자 크기, iOS는 실기 검증하지 않았다.


## 2026-09-17 추가 점검·수정

같은 Galaxy에서 기본·고급 화면을 오가며 첫 화면의 정보 밀도, 조작 순서,
한국어 제목, 단위, 스크롤 하단의 관리 기능을 다시 확인했다.

- **공기청정기 오류 수정:** 꺼진 상태에 저장된 즐겨찾기 풍량 대신 0을 발행해
  1–14 슬라이더에 ‘범위를 벗어남’이 표시됐다. 저장된 값을 그대로 발행하도록 수정했고,
  실제 전원 꺼짐·풍량 14 상태에서 오류가 사라진 것을 확인했다.
- **고급 조작 정리:** 조작음·버튼 잠금은 두 선택지 대화상자에서 한 번 누르는
  토글로 변경했다. 현재 Android에서는 둥근 버튼으로 렌더링된다.
  제목을 조작음·표시등·버튼 잠금으로 통일하고 회전 각도 제목에 °를 표시했다.
- **순서 유지:** 선풍기는 고급 화면에서도 바람 세기 → 모드 → 회전 → 꺼짐 예약 순서다.
  가끔 쓰는 회전 각도는 예약 뒤에 배치했다.
- **필터 관리 접근:** Android에서 표준 filterState의 초기화 행이 표시되지 않아,
  공기청정기 고급 프로필에 기존 filterMaintenance 기능을 추가했다.
  기존 resetFilter 처리 경로를 사용하며 기본 화면에는 관리 버튼을 노출하지 않는다.
- **문구 정리:** 현재 습도 값과 % 사이 간격을 맞췄다. 알림 제목 중복을 줄이는
  번역·presentation도 등록했으나, 최종 Android 화면에서는 이전 ‘최근 알림’ 제목이
  남았다. 기기 API의 새 presentation ID는 확인했으며 화면 반영 완료로 판정하지 않았다.

### 실제 명령 왕복

공기청정기 고급 화면에서 버튼 잠금을 켰다. 앱 → SmartThings → Edge 드라이버 →
MiOT 명령 이후 별도 암호화 LAN 조회로 실제 lock=true를 확인했다.
같은 버튼으로 해제한 뒤 lock=false를 확인했다. 두 번 모두 전원·모드·풍량은 유지됐다.
최종 LAN 조회에서도 선풍기 켜짐·35%, 공기청정기 꺼짐·풍량 14,
제습기 꺼짐·목표 55% 및 세 기기의 잠금 해제를 확인했다.

필터 초기화·알림 테스트 발송은 실제 관리 기록과 알림을 바꾸므로 실행하지 않았다.
필터 버튼의 명령 연결은 생성된 presentation → capability handler → 모델별 MiOT action
경로와 회귀 테스트로 확인했다. 모든 물리 명령을 실기에서 실행한 검증은 아니다.

### 남는 플랫폼 제약

- 관리 pushButton에 지정한 state.label은 생성된 presentation에 남지만 Android는
  상태 자리에서 ‘-’를 표시했다. 행 제목·접근성 이름은 초기화 동작을 식별한다.
  이 항목은 미관상 플랫폼 제약으로 남으며, 안내 문구가 화면에 표시됐다고 간주하지 않는다.
- 표준 기능의 전용 위젯, 상태/조작 그룹, 카드 간격·색상·아이콘은 앱이 결정한다.
- 알림 제목의 이전 문구와 pushButton의 ‘-’는 미해결 표시 제약이다.
  앱 데이터 삭제나 기기 재등록으로 사용자 설정을 초기화하지 않았다.
- iOS와 다른 화면 크기는 실기 검증하지 않았다. 현재 설치된 에어컨 화면 확인은
  별도로 진행 중인 Tuya 변경의 배포·검증을 대신하지 않는다. 최종 목록에서 에어컨은
  오프라인으로 표시돼 실제 AC 제어 왕복은 검증하지 못했다. Tuya 작업 파일은 이 커밋에 포함하지 않는다.
